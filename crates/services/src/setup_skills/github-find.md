---
name: GitHub · find issues
description: Look through the project for real problems, for Øphio to file as issues and another agent to fix.
---
Find real problems in the part of the project this task names, and change nothing.

1. Read the code there, and the tests beside it. Run read-only commands that help, such as the test suite, where they change nothing.
2. Report only what you have checked in the source: something that is wrong now, not a style preference or a guess.
3. For each one, say what is wrong; where, as file and line links; how to see it, with a test that would fail where you can; how serious it is, and how sure you are.
4. Put the most serious first. Fewer findings that are certainly real beat many that might be.
5. A security problem is marked as one: on a public repository Øphio reports it to the maintainers privately.
