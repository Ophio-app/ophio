# Desktop image encoding

`TileEncoder` implements `ports::MediaEncoder`. Live output is TDV1 with 128-pixel JPEG tiles; still output supports PNG and JPEG. It accepts the four packed 32-bit capture formats with padded rows, validates buffer bounds, and downsizes while preserving aspect ratio.

One capture task owns the source. A single latest-frame slot coalesces damage; the encoder reserves capacity before reading that slot. The output channel has capacity one, and the configured ACK window counts distinct emitted sequences. Future and duplicate ACKs do not open the window. Parameter changes and keyframe requests reuse the most recent capture even when the desktop is idle. A capture that changed nothing is still reported, at most about once a second, as a tile-free frame that keeps the previous picture, so a viewer can tell a still screen from a stalled one. Only a capture earns it: a source that delivers nothing, whether the screen is idle or the capture has stalled, sends nothing, and the viewer marks the picture stale. Windows capture hands back its last picture every quarter second after checking that the capture and its device are still working. Such a frame takes a window slot like any other, so nothing extra is sent while frames are unanswered, and it needs no pixel work. A capture marked with empty damage, at the same size and cursor position, is not compared tile by tile. Geometry notifications precede replacement keyframes. Dropping the receiver or closing control cancels capture. Expensive JPEG work runs on Tokio's blocking pool.

Stream parameters require nonzero dimensions, quality 1–100, frame rate 1–120, and window 1–16. Invalid starts or adjustments end the stream with an explicit reason. Capture permission and temporary-unavailability errors pause the stream; recovery emits Resumed and a keyframe. Other errors terminate it. Error messages do not include captured pixels or native error strings.

The default is pure Rust and builds for Windows. Linux may opt into `--features turbojpeg` to use an installed system libturbojpeg through pkg-config, without cmake or nasm. [BENCHMARKS.md](BENCHMARKS.md) records measured performance and tile-size selection.
